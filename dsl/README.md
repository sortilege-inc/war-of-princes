# War of Princes — campaign homebrew

Authored content, not captured material, which is why it sits beside `archive/` rather than in it.

| File | What |
|---|---|
| `vtm5e-war-of-princes-character-creation.ttrpg` | House rules for character creation — `EXTENSION "VTM5e_WarOfPrinces_CharacterCreation"`, depends on `VTM5e_Core_Core` 0.4 |
| `vtm5e-war-of-princes-roads.ttrpg` | The Road system, Dark Ages morality used in place of Humanity — `EXTENSION "VTM5e_WarOfPrinces_Roads"` |
| `war-of-princes-setting.lore` | Setting and premise: London and the Baronies of Avalon, 1242, under Mithras |

The three reference each other by bare filename, so they must stay in the same directory.
Their rendered versions are in `archive/reference/` (`Character Creation.*`, `Road System.*`).

Nothing builds from these: this campaign's site is hand-authored and has no pipeline.
